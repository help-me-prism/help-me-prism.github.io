2 Method

We consider a set of observations and encode each element with a shared function before aggregation.

The aggregated representation is invariant to the order of the inputs. This property allows the model to handle sets of varying size.

2 방법

관측 집합을 고려하고, 각 원소를 공유 함수로 인코딩한 뒤 통합합니다.

통합된 표현은 입력 순서에 영향을 받지 않습니다. 이 성질 덕분에 모델은 크기가 다른 집합을 다룰 수 있습니다.

짚어서 질문하기

문장, 수식, 그림을 클릭해 질문에 넣으세요. AI가 그 부분을 함께 보며 답하고, 답변에서 원문 위치로 돌아갈 수 있습니다.

구조맵으로 전체 보기

연구 문제, 방법, 결과, 한계를 한국어 개념 그래프로 정리합니다. 개념을 고르면 근거가 된 원문으로 이동합니다.

내 컴퓨터에 남는 노트

기억할 것, 질문, 아이디어를 논문별 노트로 남깁니다. 노트는 Markdown 파일이라 Obsidian에서도 열 수 있습니다.

논문 찾아 가져오기

가진 PDF를 끌어다 놓거나 제목으로 검색하세요. arXiv, Semantic Scholar, Crossref, Europe PMC에서 찾습니다.

쓰던 AI 계정 그대로

ChatGPT 또는 Claude 계정을 연결해 번역과 질문에 사용합니다. 연결은 앱의 첫 화면에서 안내합니다.

설치 방법

내려받은 ZIP에는 설치 파일과 「설치 및 실행 가이드」 PDF가 함께 들어 있습니다. 압축을 풀고 가이드를 먼저 확인해 주세요.

Windows

Windows 10·11, 64비트

  1. ZIP 압축을 풀고 설치 EXE를 실행합니다.
  2. Windows의 PC 보호 화면이 나오면 추가 정보를 누른 뒤 실행을 누릅니다.
  3. 안내에 따라 설치합니다. 시작 메뉴에 Prism이 추가됩니다.

macOS

Apple Silicon(M 시리즈) Mac

  1. ZIP 압축을 풀고 DMG를 엽니다.
  2. Prism을 응용 프로그램 폴더로 복사합니다. 이전 버전이 있으면 종료한 뒤 교체합니다.
  3. 첫 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기로 Prism을 허용합니다.

현재 베타는 Windows 코드 서명과 Apple 공증을 제공하지 않아 처음 실행할 때 위의 허용 절차가 필요합니다. 새 버전을 설치해도 기존 설정·대화·논문·노트는 유지됩니다.
